FAQ

常见问题

激活码怎么用？

打开软件，点右上角蓝色的「登录」，输入邮箱获取验证码登录（无需设置密码），然后在「设备激活」里输入激活码。激活后按钮会变成你的邮箱，弹窗里能看到剩余天数。

换电脑或重装系统怎么办？

激活码绑定的是这台电脑上的这份安装。在同一台电脑上重装软件、重新输入同一个码不会消耗任何东西。换了电脑或重装了系统，请联系我们处理换绑。

会收集我的数据吗？

登录时，服务器收到你的邮箱和一次性验证码（没有密码，验证码 10 分钟后失效，也不会存起来给下次用）；激活和启动复查时，收到激活码和软件首次运行时随机生成的一个编号。不读取任何硬件信息，也不记录你下载了什么——解析和下载完全在你本机进行，服务器看不到。从没登录过的电脑，完全不会连接我们的服务器。

没网的时候还能用吗？

已激活的电脑，14 天内连不上服务器也照常使用，网络抽风不会影响你。超过 14 天会暂停，联网后自动恢复。

为什么 YouTube 有时只有 1080p？

YouTube 按出口 IP 判断你是不是机器人。机房 IP（大多数代理节点）很容易被拦，这时只能拿到登录后的 1080p60。换一个干净的节点，通常就能直接拿到 8K。

Windows 提示「未知发布者」？

NovaPull 目前还没有购买代码签名证书，所以 Windows 会显示这个提示。点「更多信息 → 仍要运行」即可。请只从本站下载安装包。
